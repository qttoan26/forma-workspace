# Architecture Decision Records

Forma Workspace records decisions that materially affect architecture, dependencies, development workflow, or long-term product constraints.

## ADR format

```md
# ADR-NNN: Decision title

- Status: Proposed | Accepted | Superseded
- Date: YYYY-MM-DD

## Context

What problem or constraint requires a decision?

## Decision

What are we choosing?

## Consequences

What becomes easier, harder, or intentionally constrained?

## Alternatives considered

What credible alternatives were evaluated and why were they not selected?
```

ADRs should document meaningful trade-offs, not every implementation detail.
